# Virtual Electronics Lab

A browser-based virtual electronics laboratory featuring interactive experiments:

- Ohm's Law
- Series & Parallel Resistance
- Kirchhoff's Voltage Law (KVL)

## Run locally

Open `index.html` in a modern browser. No installation is required.

## Publish with GitHub Pages

1. Create a public GitHub repository.
2. Upload the contents of this project folder (including `index.html`, `experiment.html`, `css/`, and `js/`) directly to the repository root.
3. In the repository, go to **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose **main** and **/(root)**, then Save.
6. After deployment, GitHub will display the website URL in the Pages section.

## Experiments

Each experiment includes learning sections, a demo, observations, a test, and a conclusion. Experiment 2 includes series and parallel circuit samples and checks.
